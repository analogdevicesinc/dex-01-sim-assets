# DEX-01 PhysX backend package

This package contains the Isaac Sim 5.1 sensor implementation under
`dex01_sim_asset`. Install through `physx/setup_env.sh` or alongside the local
`dex01-sim-common` distribution inside a compatible PhysX environment.
It does not include a Newton backend or shared pattern copy.
