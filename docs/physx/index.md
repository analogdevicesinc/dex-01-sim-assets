# PhysX environment

This track uses Isaac Sim 5.1 and Python 3.11. Its code, installer, backend
package and tests live in the repository's `physx/` directory. A separate
[Newton track](../newton/index.md) targets Isaac Lab 3.0 Early Access.

Start with [installation](installation.md), run the [first simulation](quickstart.md),
then [attach](attachment.md) a sensor and [validate](validation.md) your scene.
The [shared data reference](../reference/data.md) explains the resulting arrays.

Bundled videos retain their capture provenance. Rerun physical fixtures and
captures when changing layouts or geometry.
