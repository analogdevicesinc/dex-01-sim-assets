# Choose example environment

Choose the installed environment before launching an example. Each gallery
and command set belongs to that environment.

<div class="environment-cards">
<a class="environment-card" href="../physx/examples/"><strong>PhysX examples</strong><span>Flat grid, Tesollo hand and stationary pressing.</span><span>Recorded PhysX videos with source and geometry provenance.</span></a>
<a class="environment-card" href="../newton/examples/"><strong>Newton examples</strong><span>Single curved fingertip, known hand load and joint-driven pressing.</span><span>Verified Newton hand and press captures with independent force and geometry checks.</span></a>
</div>

Both environments use the same DEX-01 geometry and firmware mapping.
The flat-grid PhysX example and single-fingertip Newton example are different
scenes. Solver settings, gear dimensions and validation results must follow
the selected environment.
