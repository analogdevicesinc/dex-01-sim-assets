# Support by environment

Use [PhysX troubleshooting](physx/troubleshooting.md) for Isaac Sim 5.1,
compliant-contact and RTX startup issues. Use
[Newton troubleshooting](newton/troubleshooting.md) for EA setup, binding,
mesh validation and native contact errors.

When opening an issue, include the environment, repository revision, command,
Python/simulator/package versions, GPU/driver, final log lines and any failed
verification report. Run `git lfs pull` if simulation files are LFS pointers.
A documentation or encoder test is not a substitute for a failing live fixture.
