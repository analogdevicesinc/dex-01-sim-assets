  1. Robotiq 2F-85

Grasp, hold, and release

The Robotiq 2F-85 closes its two rectangular tactile fingers around a free rigid block, holds contact, and opens again. Each finger produces a 32 × 32 tactile frame. Gravity and damping are disabled on the block so its movement reflects the gripper’s contact forces.

Run the example

From the repository root in the installed environment:

python scripts/dex01_on_robotiq_2f85.py

The example runs one six-second cycle at 240 Hz. Its fixed-base gripper acts on a 0.1 kg, 10 × 30 × 18 mm block. Isaac Sim loads the official gripper from its configured asset library; see the Robotiq integration guide for a local library or an alternative asset root.

Read the tactile output

Both frames start unloaded, develop a contact footprint as the jaws close, and return to zero after release. The labels show each finger’s total normal force in newtons. During hold, the two loads should be close; the block can move in response to any imbalance.

View each contact face with its fingertip up: rows run tip to base and columns left to right. All 1,024 pixels correspond to sensing sites. See display colors and units.

Because gravity is disabled, the readings represent the grasping load rather than the block’s weight. Use the grasp validation for independent force and momentum checks. For mounting, asset reuse, and rebuilding, see the integration guide.
