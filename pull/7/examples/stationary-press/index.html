Stationary-object pressing

Finger 2 of the Tesollo hand bends toward a fixed gear, holds contact, then retracts. The wrist and gear remain stationary, so the changing tactile footprint follows the finger’s motion.

Run the example

From the repository root in the installed environment:

python scripts/dex01_stationary_press.py

The default cycle lasts 2.5 simulation seconds and repeats until closed. --press-time-scale changes the trajectory duration; elapsed wall-clock time also depends on host performance. For remote viewing, follow the streaming setup.

Read the tactile output

Finger 2’s frame becomes active during approach and hold, then returns to zero after retraction. The other four frames remain unloaded. The contact close-up shows the fingertip’s planar patch meeting the gear’s underside; the loaded samples surround the central hole.

The displayed load is the measured normal contact force. The controller’s force setting is a contact-seeking threshold, so it does not guarantee a constant force during hold. Individual gear teeth may be too small to resolve on this fingertip grid. See display colors and units.

Use the articulated-press validation to check motion, alignment, contact coverage, and release. For a stationary hand with a repositioned object, see sequential fingertip contact.
